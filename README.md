# 🛒 E-Commerce Sales & Customer Analytics using MySQL

## 📌 Project Overview

This is my first SQL portfolio project, focused on analyzing an e-commerce database using **MySQL**.

The project explores customer behavior, order performance, revenue trends, payment methods, and other business-related questions using SQL.

I created and analyzed a database containing **Customers, Orders, Sellers, Products, and Payments** tables and solved **26 business questions** using different SQL concepts.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze customer and order data.
- Understand sales and revenue patterns.
- Identify high-value customers and orders.
- Analyze customer spending behavior.
- Practice SQL queries used in real-world business analysis.
- Apply intermediate and advanced SQL concepts.
- Build a strong foundation for future Data Analytics projects.
